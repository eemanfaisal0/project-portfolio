# Mobile Robot Orientation Estimation Using Sensor Fusion

## Project Overview
Developed an adaptive Kalman filtering approach to estimate robot orientation using IMU sensor data.

## Technologies Used
- MATLAB
- Kalman Filtering
- Sensor Fusion
- IMU Data Processing

## Key Contributions
- Developed an adaptive Kalman filter for robot orientation estimation.
- Cleaned and processed sensor data to address noise and inconsistencies.
- Compared performance against standard EKF and Q-AKF approaches.
- Achieved improved roll and pitch estimation accuracy.
