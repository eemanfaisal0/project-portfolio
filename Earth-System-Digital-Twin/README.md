
# Earth System Digital Twin – Rainfall Forecasting

## Project Overview
Developed an LSTM-based deep learning model to downscale coarse-resolution climate data into 25 km precipitation estimates for Punjab, Pakistan.

## Technologies Used
- Python
- LSTM (Deep Learning)
- ERA5 Climate Data
- Geospatial Data Processing
- GRIB and GeoTIFF

## Key Contributions
- Developed an LSTM-based rainfall prediction model.
- Processed ERA5 climate variables using spatial and temporal information.
- Built a data-processing pipeline involving GRIB-to-GeoTIFF conversion, resampling, scaling, and sequence generation.
- Evaluated model performance using MSE, RMSE, and MAE.
